Open presentation.obj in a mesh editor with units set to mm and z-up-right-handed. Each box has 8 vertices and 6 outward quad faces. An N-sided cylinder has 2N vertices, N outward side quads and 2 outward ngon caps, centered on translation with axis +Z and its first vertex at +X. Sides must be an explicit integer 8–256. Cylinders are faceted inscribed polygons with no smooth normals. See per-cylinder approximation losses. Nominal primary-mass width/depth is twice radius; actual mesh bounds can be smaller, especially for odd side counts. All input dimensions/translations remain mm; OBJ values convert to declared units.
