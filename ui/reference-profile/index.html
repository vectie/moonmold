Extrude an editable profile

Need a sleeve or stepped collar? Revolve a radius–height profile.

Turn a straight-edged XY outline with an optional interior cutout into a capped 3D reference. Revise the outer points, opening or height, save the profile, then place the derived mesh in your reference layout.

Digital reference geometry only. No engineering CAD, tolerances, material behavior, Blender qualification, manufacturing or physical authority. One simple outer ring and at most one strictly interior polygon cutout, each 3–128 points. No multiple openings, curves, repeated closing point or collinear corners.

Raw user-space coordinates only. Unrounded rectangles produce four corners. Circles, ellipses and one explicitly closed absolute M/L/Q/C/Z path use your explicit error limit and at most 128 editable points. Curves become straight segments; error uses the selected units below. SVG width, height and viewBox are hints and are never used to infer scale. The import replaces the current outer outline and cutout. No rounded rectangles, relative commands, path arcs, transforms, CSS, references, compound contours or automatic holes. Style and stroke widths do not become geometry. Save the import record to retain exact SVG bytes, approximation and initial recipe identities.
Outline and extrusion Clockwise or counterclockwise is accepted. The closing edge is automatic. Concave outlines are supported; crossings, touching edges and numerically ambiguous geometry are rejected. Leave blank or enter null for no opening. One simple polygon strictly inside the outer outline, in the same units; either winding is accepted. Touching, crossing, outside and numerically ambiguous openings reject.

Base is Z=0; XY and height use the same explicit units. Changing units reinterprets all numbers; it does not convert the entered numbers. Output is millimetres.
